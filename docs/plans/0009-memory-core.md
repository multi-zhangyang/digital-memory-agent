# 阶段九：文字记忆核心

> 历史阶段记录：保留当时的决策、实测和限制。当前产品以 [产品定义](../product.md)、[架构](../architecture.md) 和 [Harness 重构计划](0018-harness-refactor.md) 为准。

## 目标

将已有通用 Agent 工作台接入可持续积累的个人记忆。用户授权由开发方编写虚构经历验证流程；示例与真实记忆隔离。小参数模型训练、嵌入模型、图片及视频理解继续后置。

## 本阶段范围

- 文字记录、文本文件及已有资料的批量导入；SQLite 持久化分段进度、取消、重试和重启恢复。
- 复用 Pi 的模型与供应商适配，用结构化提取生成待核对的资料观察及推断；保存原文引句、字节位置、摘要哈希、模型及处理版本。
- 关于我、经历时间线、文字人物索引；确认、排除、纠正与显式替代冲突信息，保留版本历史。
- 有大小预算的已确认画像与关键词/人物/日期召回。最新版本在跨会话与重启后生效；历史记录可显式检索。
- 记忆工作台中的导入、真实处理状态、候选审核和虚构示例入口，沿用 shadcn/ui 组件。

## 验收

1. 批量文本经过实际模型适配产生有原文证据的候选，未经确认不进入个人召回。
2. 重复导入不重复调用模型或复制同一段的记忆；取消、失败重试、重启不丢失已完成部分。
3. 矛盾的单值画像须显式处理，不能悄悄覆盖；纠正后检索及人物索引使用新版本。
4. 虚构示例即使确认也不进入真实个人记忆、默认资料搜索或 Agent 上下文。
5. 后端、浏览器及有界真实模型检查；准确区分测试替身与真实调用。现有通用 Agent 工作流继续通过回归。

## 已实现

- 导入任务及每段状态写入 SQLite，固定模型与思考强度。内容哈希、范围和提取版本控制重复处理；候选、去重回执与段落完成状态原子提交。取消保留完成部分，失败可重试，重启恢复未完成段落。
- Pi 模型适配器进行真实结构化提取，所有结果先保存为草稿。服务端核对原文引句，计算 UTF-8 字节范围，拒绝不存在的证据、虚构日期与无效画像占位符，保留推断的不确定性。
- 个人记忆页面支持文字、文件与已有资料导入，画像、时间线、文字人物索引、批量核对，以及有版本校验的纠正和冲突替代。可打开原文和历史修订。
- 每轮自动取用有限画像和相关记忆，完整序列化内容受 12,000 字节预算约束；检索支持关键词、人物、类别、日期与显式历史记录。发送模型上下文时只保留当前自动记忆快照，旧检索结果标为过期。
- 四份虚构示例独立存于 `examples/experiences/`。产品入口实际调用所选模型，保存到 `demo` 空间；确认后仍不进入真实个人召回或默认资料搜索。

## 验证

- 类型检查与生产构建通过，后端 41 项测试通过。新增测试验证原文证据、中文字节定位、持久化去重、失败重试、取消与重启、文件篡改拒绝、原子冲突处理、版本更新与示例隔离。
- 接入记忆核心后的完整浏览器回归 23 项通过；最终的小幅调整后，记忆与工作台相关 10 项再次通过。后续统一 AI Elements 的最终回归记录在 [第十阶段](0010-ai-elements-runtime.md)。
- 使用已配置的 `gpt-6-luna`、`low` 思考强度进行真实验证：四份虚构记录经四次提取产生 12 条候选，其中一条保留事件是否发生的不确定性。确认并替代居住地后，新会话回答使用苏州；纠正散步日期并重启服务后，新会话通过实际记忆检索回答更正后的 2026-03-15。
- 真实验证在独立临时数据目录执行，只使用虚构文字，未写入用户日常个人库。原始调用与报告保存在被 Git 忽略的 `.data/`。自动化测试只有外部模型由本地替身提供，Pi、SQLite、HTTP、SSE 与文件系统均实际执行。

## 当前边界

- 这是 Agent 的持久文字记忆，尚未训练个人参数模型，也未引入嵌入模型、OCR、图片/视频理解或视觉身份识别。
- 人物仅按文字称呼索引，不自动证明同名人物或别名属于同一个人。结构化单值画像可检测冲突，任意自然语言矛盾仍需用户核对。
- 提取以有大小上限的片段执行，不保证跨片段事件自动合并。导入从记忆页面启动，普通聊天可检索与提出候选；不能将此阶段称为全模态自主采集。
- 通用 Agent 的执行任务在重启后仍由用户选择重试，避免自动重放带副作用的工具。只有持久化文字导入使用可恢复分段流程。
