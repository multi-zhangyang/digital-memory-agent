# digital memory

把个人的图片、文字、视频与标注交给 Agent，由它整理资料、查找证据、维护记忆，并交付可核验的训练文件。

项目建设两个相互协作的产物：**数字记忆 Agent** 使用可替换的 AI 与基于 Pi 自研的 Harness 完成任务；**个人记忆模型** 通过真实训练把经历学入参数，能够独立运行并接受闭卷评测。当前已实现 Agent 和训练数据准备流程，个人模型训练仍暂停，尚无个人模型权重或训练效果。

界面采用官方 shadcn/ui 与 AI Elements，黑白配色，默认深色主题。工具输入、执行结果、失败、来源和交付随任务保存。

## 快速开始

需要 Node.js 24、pnpm 12.6.0。脚本沙箱目前使用 Linux / WSL2 的 bubblewrap；本地资料管理和界面不要求 GPU、Docker 或外部数据库。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://localhost:3000，Agent 默认运行在 http://127.0.0.1:4310。

在「设置」添加模型连接，填写接口地址、API key 和实际模型标识，选择协议，再「保存并测试」。支持 OpenAI 兼容的 Chat Completions / Responses 及 Anthropic Messages。可配置多个连接，并调整上下文窗口、输出长度和思考强度。图片处理需启用图片输入，并由实际模型接口支持。

在「设置 → 个人记忆」选择自动整理策略、独立处理模型和本地索引。主 Agent、文字、照片、视频画面、问题生成与样本核验可以使用不同模型。视频自动处理默认关闭。保存配置与实际能力验证分别显示。

可复制 [.env.example](.env.example) 为 `.env` 调整服务地址和数据目录。修改 `AGENT_PORT` 时同步修改 `AGENT_ORIGIN`；自定义 Web 端口时同步配置 `MEMORY_ALLOWED_ORIGINS`。

## 用 Agent 完成任务

1. **整理资料**：上传图片、文字或视频，说明目标。会话附件先保存原件，再由 Agent 选择处理方式；直接在资料库上传按已启用策略处理。后台作业可独立运行、取消和恢复。
2. **查找与回忆**：结合关键词、语义、人物和时间查找资料，按需对照原文、原图局部及视频画面时间。未确认观察可以作为素材证据，个人事实按确认规则取用。
3. **核对与纠正**：明确确认、更正或停止使用某条记忆。记录用户指令、依据及前后版本，并追踪受影响的关联、索引和训练样本。
4. **准备数据集**：冻结合格记忆及来源版本，生成训练题和关联评测题，批量核验。Agent 可定位失败题、逐题修订、排除或留待核对，再交付实际文件。

数据集产物包括 `training.jsonl`、`evaluation.jsonl`、`review.jsonl` 和 `manifest.json`。待核对题退出训练与评测文件；明确处理后的部分交付可以结束任务，原核验失败和后续依据同时保留。纠正后按原范围重建，未变化样本的有效审阅决定可以沿用。

资料、个人记忆、数据集、人物和处理记录也提供直接操作入口，与 Agent 共用业务服务。工作台继续提供项目文件、脚本沙箱、终端、差异、联网工具、扩展和 Pi 会话控制。

## 当前边界

- 素材观察、用户确认事实、检索索引和模型参数分别管理。模型输出、人物聚类和会话摘要不会自动成为个人事实。
- 本地文字、图像和人脸编码器已接入独立处理器；部署与实际对照见[本地处理方案](docs/local-memory-processing.md)。人物候选允许未知身份，当前阈值尚未经过个人相册的大样本验证。
- 视频支持抽样画面、时间定位、原件索引和人物出现；音频转写尚未实现。抽样可能遗漏短暂事件。
- 真实模型已贯通会话内处理、样本核验和文件交付。历史视觉误识别、问法和依据错误仍保留；流程通过不代表语义准确率或个人模型记忆效果通过。
- 当前为单用户本机应用，没有公网身份认证与多租户能力。训练调度、个人模型权重与独立闭卷评测尚未交付。

## 代码与数据

| 目录 | 职责 |
| --- | --- |
| `apps/web/` | Next.js 工作台、shadcn/ui 与 AI Elements |
| `apps/agent/src/harness/` | 任务、上下文、工具与持久执行状态 |
| `apps/agent/src/integrations/pi/` | Pi 会话与模型适配 |
| `apps/agent/src/memory/` | 素材、记忆、检索和数据集业务 |
| `apps/agent/src/application/`、`storage/` | 服务装配、公开接口与版本存储 |
| `packages/contracts/` | 前后端共享协议 |
| `services/memory-worker/` | 本地编码器、固定模型清单与 Python 依赖锁 |
| `examples/` | 虚构经历、公开素材清单与复现脚本 |
| `docs/` | 产品定义、架构、交接和历史验证 |

私人运行数据默认位于 `.data/`：模型配置、数据库、原件、会话、项目、检查点、数据集和编码器缓存。密钥由服务端保存，不回显已保存值，不在浏览器持久化。私人数据、模型权重、日志和生成目录均不进入 Git。

记忆备份与完整工作环境备份的范围不同，恢复步骤见[数据集与恢复](docs/local-memory-processing.md#数据集与恢复)。外部工作目录需要单独备份。

## 开发与验证

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```

浏览器测试使用独立数据目录和本地模型协议替身，验证交互与业务状态；真实模型验证另外记录。生产验证可使用独立构建目录，避免覆盖正在运行的版本：

```bash
AGENT_ORIGIN=http://127.0.0.1:4311 MEMORY_NEXT_DIST_DIR=.next-e2e pnpm --filter @memory/web build
E2E_PRODUCTION=1 pnpm test:e2e
```

真实模型评测命令位于 [Agent 脚本](apps/agent/package.json)，需已配置连接，会产生 API 调用；材料范围、失败和效果分别记录在对应阶段。公开素材及虚构样例不导入个人资料库。
