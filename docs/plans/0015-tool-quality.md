## 范围与验收

这轮沿用阶段十四的服务与工具边界，检查视觉描述、人物候选关联和记忆检索的实际错误。改动留在对应服务及评测工具中，不增加主 Agent 的逐张处理、索引维护或进度轮询工作。

1. 通过 Exa 查找许可明确的公开照片，保存原始来源、作者、许可、摘要和变换记录。原件只保存在隔离评测目录；处理器仅接收中性文件名及图片字节，不能读取来源页中的人物姓名或描述。
2. 固定开发样本与保留样本。文字使用明确标注的虚构经历，覆盖近似事件、日期、否定、纠正、身份歧义及缺少依据的问题。人物关联使用多张独立照片，图像变换只作为附加稳健性测试，不冒充更多独立照片。
3. 先在开发样本上保留当前实现的原始输出，逐项诊断漏检、错误关联、错误排序和无依据描述；对可复现问题修正对应服务。事实内容由原图/原文核对，另一个模型的赞同不能作为真值。
4. 修正方案固定后才查看保留样本结果，报告当前实现与基线的差异、剩余错误、延迟和证据范围。开发成绩与保留成绩分开，不把小样本结果宣称为通用准确率。
5. 运行与行为变化相关的回归；只有真实改进且原有边界没有退化才更新本地服务。保留原有私密配置和资料，不把测试材料添加到用户记忆库。

## 实际改动

两项行为改动均位于 `MemoryQueryService`，未增加 Pi 主 Agent 的逐条处理工作：

- 查询中的完整字母数字编号在当前合格候选中优先，例如 `SF38469257` 不再被相似的 `SF38469251` 抢到前面。完整词项经过规范化，不匹配编号前缀、普通词或年份；原始旧证据不能恢复已纠正编号。回归覆盖当前版本、来源停用、空间、人物、时间和未配置向量的情况。
- “找……照片”的单句视觉描述长度从 20 扩至 200，避免长描述未走图像通道。句号、问号、感叹号和换行仍截断意图范围；普通照片存放问题和 event 类查询继续使用文字路径。测试中的固定向量只验证路由，真实检索另用本地编码器。

新增固定清单、可续传下载器、独立文字与图像评测脚本，使用方式见[评测材料说明](../../examples/quality/README.md)。图片预处理和人物候选服务未改。显式 `detail=high` 仅为隔离实验，错误仍在，不写入正式视觉处理器。
