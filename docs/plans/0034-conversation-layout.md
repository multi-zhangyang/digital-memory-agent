## 核心任务与变更

用户从会话提交资料与目标，阅读真实执行过程，打开成果或来源，再继续纠正与交付。界面围绕这条任务路径重新布局。

- 新对话使用居中输入，工作区默认关闭。
- 侧栏改为最近会话，工作目录从常驻树移入附件与工作区菜单。
- 顶栏合并会话操作与工作区入口，保留 Pi 会话和能力。
- 宽屏按需分栏；1024px 与手机使用全宽查看层。
- 明确打开对象与恢复上次标签分别处理；普通流式更新不抢占查看焦点。
- 继续使用官方 AI Elements 与 shadcn/ui，调整正文、输入和成果摘要的阅读层级。

## 收尾结果

2026-10-05 完成实现、回归与本机启用。中断前的代码继续保留，收尾补齐了以下问题：

- 工作区把明确打开对象与恢复标签分开；刷新通过 URL 的 `workspace=1` 恢复开关状态。普通流式更新和任务完成不抢占当前查看对象。
- 创建或重新打开工作目录时，文件面板请求绑定到目标目录的新会话标识，避免沿用旧会话请求。清理侧栏改版后不再使用的目录回调。
- 返回已访问的文件标签时重新读取文件列表，使其他操作产生的新文件可见；保留文件编辑草稿。
- 菜单关闭时不抢走已进入输入框的焦点；更新旧入口、旧文案及多标签场景下的浏览器断言，保留原有业务验收。
- 开发模式首次查看差异时，Pierre Diffs 1.3.6 会把 StrictMode 重新挂载留下的空 `<pre>` 当作已有内容。应用层按需调用公开的 `preloadHighlighter`，在挂载前加载内置主题；未修改上游包，未关闭 StrictMode。
