## 本轮交付

1. Agent 与直接页面共用视频原件核验、指定时间画面读取和局部像素读取。时间点、视频时长、原件与返回画面摘要随来源保留。
2. 独立后台按配置抽样整理视频，保留每个画面的处理状态、观察、时间和模型。图片、文字、视频可在同批处理，重启与重试沿用现有作业机制。
3. 检索返回视频及其待核对观察；核对、确认、纠正、停止取用与数据集共用现有业务规则。抽样画面不能代表全部内容或声音转写。
4. 会话工具结果、素材检索和记忆来源显示画面与时间，能定位到原视频。设置提供视频模型、抽样间隔和自动处理开关，使用官方组件，不显示开发说明。

## 实际实现

- `video-source` 核验完整原件，用宿主 FFprobe/FFmpeg 解码 MP4、WebM、Ogg；先处理方向，再从原始像素裁剪，返回去元数据 JPEG。最多 1 GB、2 小时、单帧 4,000 万像素；实际上传仍受 `MEMORY_UPLOAD_LIMIT` 控制。只向允许的视觉模型发送本次所需画面，不发送原视频或声音。
- `SourceRef.video` 同时保存请求秒数、实际帧时间、时长与音轨存在信息；字节范围仍表示完整原件。实际 4 fps 视频请求 2.2 秒返回 2.25 秒，并保存原件、返回像素摘要和区域。来源去重保留同一原件的不同时间及视图。
- 视频每帧独立保存状态、模型、调用次数和观察。默认每 10 秒抽样，含首尾，最多 120 帧；长视频扩大间隔。视频模型可单独配置或沿用照片模型，自动处理默认关闭。改间隔后重新提交会处理新时间点，重合帧沿用回执，后台不依赖 Agent 会话维持。
- Agent `process_assets` 与直接「处理所选」共用服务；文字、照片和视频按各自处理模型组成一批。处理中心与 `read_job_result` 分页展示每份原件的成功、复用、失败和视频覆盖；既有重试、停止及恢复继续使用同一作业机制。
- `read_evidence` 与原件预览共用解码及摘要核验。Agent 自主修订视频观察须真正读取同一时间的画面，其他帧和观察文字不能替代；修订保持草稿。确认、纠正、停用和数据集依赖保留原件与帧来源。原件文件名及观察正文参与检索，尚未接入原始视频帧向量索引。
- 界面组合官方 AI Elements Tool/Attachment/Sources 与 shadcn Dialog/Field/Tabs/Switch/Select；原生 video 播放同源原件。显示实际画面、时间、输入、结果和失败，来源定位与刷新恢复一致，移动端时间独立展示。处理中心与设置去除开发说明文字。
- 真实任务发现 `confirm` 忽略显式修订字段，留下未解决不确定性。现在确认与显式 `patch` 在同一版本提交，与直接编辑一致；仅用户要求的修订清空不确定性，确认本身不自动清空。原错误、空数据集和修复后的任务均保留。

## 真实模型及独立内容核对

`video-memory-live-gTQ0zI` 使用真实配置的 `gpt-6-luna`、Pi 和独立服务，只处理程序生成的 6 秒标签视频及明确虚构的交接文字，不读取用户资料库。视频 2 fps，开始标签 VN73，2 秒后为 VN79。预置 2.5 秒错误草稿 VN78 是故障注入，并非真实提取自然产生的错误。

- 首次背景视频作业处理 0、2、4、5.5 秒画面，保留未知经历日期；随后的主动复核出现供应商 `Connection error`，首次读取、修订和成果完整性未通过。文字确认携带的修订被旧实现忽略，不确定性未清除，首次数据集正确排除该记录而为空；任务未完成交付。原失败报告在续作前保存。
- 重启后 Agent 查找并实际读取 1、2.5、4 秒原件，保存 VN73 → VN79 的时间来源成果。续接任务读取 2.5 秒整帧与标签局部，并读相邻 2、3 秒画面；草稿当前判定改为 VN79，VN78 仅保留为修订历史。依据由成功读取构成，回执保留时间、区域和前后版本，状态仍是 draft。
- 续接文字任务按明确用户指令更新已确认正文及不确定性，实际构建并审阅 3 道题，交付 2 条训练、1 条评测、0 条待审，全部实际下载并核验摘要。答案的接收方向、位置与日期对照确认正文正确；评测只是同一事实的不同问法，未训练。
- `report.json` 保留首轮失败检查及续作的 6/6 检查，`independentSemanticReview` 记录原始像素、草稿历史、样本和文件对照。续作草稿正文保留旧编号的错误历史，因此判定检查针对当前结论，不要求删除追溯文字。原报告未改成首轮全通过。

真实模型实验分别提交视频和文字作业；同批混合处理由真实解码与受控处理器回归验证。真实交付的题目来自确认文字；视频时间来源进入训练文件、纠正使旧交付失效由受控回归验证，不能声称已经实测真实模型从视频事实生成个人训练问答。

当前效果只证明简单平面标签、小字和一次编号变化的复核；自然视频、复杂动作、人物关系、声音、完整内容覆盖均未通过质量验收。媒体阶段的自然照片误识别仍存在。能力状态保持 `not-verified`，尚无一轮未经后续续接的完整实测同时满足全部检查。
