# 第三阶段：Agent 工作台与第一层个人记忆

> 历史阶段记录：保留当时的决策、实测和限制。当前产品以 [产品定义](../product.md)、[架构](../architecture.md) 和 [Harness 重构计划](0018-harness-refactor.md) 为准。

状态：2026-10-03 已实现并完成集成验收。下列清单记录本阶段实际交付；缩减项与后续能力单独列出。长期原则继续由 AGENTS.md 管理。

设计依据见 [Agent 工作台研究](../design/0001-agent-workspace-research.md)。

## 目标

首先交付一个真实流程：在对话中选取文字资料，Agent 持续处理，用户查看执行记录和来源，打开并修订整理结果，将有依据的信息保存为可在新任务中使用的记忆。

这次需要同时补齐交互与 harness。嵌入模型、人物自动识别、个人模型训练、Colab 和任意电脑操作继续保持后置。

## A. 工作台与输入资料

- [x] 用官方 Sidebar、Command、Resizable、Sheet 组合工作区；右侧按当前资料或结果打开。
- [x] 对话内上传、从资料库选择、多文件附件预览与移除；记录附件和任务关联。
- [x] 草稿与选中资料跨导航保留；任务与资料支持直接定位的地址。
- [x] 会话重命名、收藏、归档、删除和搜索；删除界定为会话及其派生记录，不连带删除原始资料。
- [x] 模型与本次思考强度入口；服务端区分连接默认值与运行覆盖值。
- [x] 一次选取多份资料开始整理，支持只针对选中资料执行。

验收：用户导入两份文字记录，在同一个工作区选择它们、提问、打开原件、返回输入框，草稿和选择不丢失。附件显示的资料与服务端实际可读取的范围一致。

## B. 任务执行与历史

- [x] 持久化 Run 和有序 RunEvent；一次任务中的多次执行可关联。
- [x] 将生成任务与浏览器 SSE 连接解耦，提供事件游标及重新订阅。
- [x] 执行中、等待输入、失败、停止和成功分别记录；重试创建新 Run。
- [x] Pi 事件转为真实的任务进度、工具调用、资料读取、结果与错误。
- [x] 使用 Task / Tool 组织执行详情；有结构化计划时使用 Plan。
- [x] 补充指令队列持久化，支持撤回待执行项；不静默打断正在执行的写入。
- [x] 展示供应商实际返回的使用量；未提供的计量不伪造。

验收：执行过程中刷新或切走后返回，可以重放同一任务的真实事件；不重复执行工具。停止后记录为已停止；错误可定位到步骤。服务重启后的未完成任务有明确状态，不直接显示成功。

## C. 结果与来源

- [x] 保存 Artifact 与版本，首期支持 Markdown 整理笔记与时间线。
- [x] 结果可在右侧预览、修订、重新引用和导出；会话中保留入口。
- [x] 定义 SourceRef，保存资料、版本与原文位置；服务端验证引用范围。
- [x] Sources 连接带字节范围的原件预览；引用失败显示不可用状态。
- [x] 用户修改与 Agent 修改分别记录，避免后续生成覆盖用户修订。

验收：一次整理生成可重新打开的结果，用户能从结论定位原文并修改结果，刷新后修改仍存在；无法提供依据的内容不会展示伪造引用。

## D. 第一层真实个人记忆

- [x] 记录 MemoryEntry、证据关联、确认状态、发生时间与修订记录。
- [x] 从任务中提出有来源的记忆草稿，支持纠正、合并、驳回和撤销保存。
- [x] 用户直接陈述、素材观察、模型推断分别保留；不将压缩摘要自动写成事实。
- [x] 以中文分词和 SQLite 关键词匹配实现有限召回，控制注入上下文的数量与大小。
- [x] 工作区显示本次使用的记忆；新任务可查询已保存内容及其来源。
- [x] 记忆页面提供总览、时间线、搜索、待核对项和已排除项。

验收：用户在任务 A 保存一条有来源的信息，新建任务 B 后可被召回；更正后召回新版本，并能查看旧版本和原因。拒绝保存的信息不能作为已确认事实进入后续上下文。

## 后续多模态接入

图片与视频保持原件、预览和来源 ID。下一阶段分别接入图片描述/OCR、音视频转写、关键帧与时间段定位，再讨论人物聚类和身份关联。需要确认所选模型或专用服务的实际能力，不能仅根据 UI 附件或模型名称推定支持视觉。

一个人物关联多个素材、未知身份、误聚类合并/拆分、一次确认影响范围，应作为完整工作流设计。训练数据与个人记忆模型仍是后续独立产物。

## 数据对象与前后端契约

| 对象 | 职责 |
| --- | --- |
| Conversation | 用户协作记录，关联多个 Run |
| Run | 本次目标、模型参数、资料范围、状态、开始结束时间 |
| RunEvent | 有序事件与重放游标，引用原始工具调用 |
| ConversationAsset / RunAsset | 显式资料选择与实际执行范围 |
| Artifact / ArtifactVersion | 整理产物、作者、版本和修订关系 |
| SourceRef | 稳定资料标识、版本和可定位的证据范围 |
| MemoryEntry / MemoryRevision | 个人信息、状态、证据、有效时间与纠正历史 |

Pi JSONL 继续保留模型会话记录；应用数据保存任务、结果与个人记忆。两者通过稳定标识关联，不用 UI 消息数组代替事实库。

## 实际实现与后续边界

- 首期结果为 Markdown 笔记/时间线，未实现独立的结构化事件实体、逐句 InlineCitation 或按事件有效区间查询。Sources 登记实际读取的原文范围，不冒充逐句事实核验。
- 记忆召回使用关键词匹配，没有嵌入、向量索引或人物图谱。发生时间可填写和排序，尚不做自然语言日期归一化。
- 浏览器断线与导航不会停止 worker；服务进程重启后标记中断，当前不自动恢复执行，避免重复写入。
- 资料范围由工具服务端强制执行；同一任务已有的对话历史仍会使用。关闭个人记忆检索只阻止新的召回。
- 删除任务保留原件与独立记忆；记忆合并保留原修订历史，合并结果重新待核对。
- 图片/视频理解、人物关联、训练数据集与个人模型训练继续后置。

## 验证记录

- 类型检查通过；服务端 16 项测试通过。覆盖真实 Pi 工具循环、资料范围与伪造来源拒绝、记忆确认/纠正/合并及版本冲突、排队/停止/等待输入、事件重放、重启恢复、配置与密钥边界。
- 六项桌面/响应式浏览器流程通过：资料集合与草稿、模型设置、结果版本与跨任务记忆、断线队列、用户补充与错误、12 MiB 原件校验和字节范围。另行验证手机完成任务并确认记忆。截图仅保存在忽略的 test-results 目录。
- 浏览器使用实际应用、Pi、SQLite 和 SSE；外部模型协议由本地测试服务替代，文本测试传输使用官方 @shadcn/helpers。上述自动测试不消费用户 API。
- 使用用户配置的 gpt-6-luna / Responses，在独立私人数据目录运行虚构验收记录。真实 read_asset_text、write_artifact、propose_memory 均成功；确认后新任务通过 search_memories 正确回忆同行人与路线。
- 首次 medium 验证在一次工具调用后超过 180 秒测试期限；随后缩短指令、使用 low，完整流程通过。这个结果证明本次链路可用，不代表对供应商延迟和稳定性的保证。没有进行 256K 满上下文压测。
- 私人 API 配置保持在 .data，未加入版本管理；既有用户原件与会话保留。AGENTS.md 未写入阶段任务。

生产构建通过，已在本机 3000 / 4310 端口启动新版。实际生产浏览器检查通过：默认深色、主题切换、原有会话打开、模型参数恢复、保存密钥不回显，页面运行错误为零。手机端额外验收通过资料整理、结果查看、确认记忆及记忆页导航；浏览器验收合计七项。
