## 真实模型与语义对照

使用已配置的 `gpt-6-luna`、真实 Pi 和真实业务服务，独立临时数据库；材料是三段虚构经历文字与已有许可清单中的公开咖啡杯照片，没有使用私人资料或进行模型训练。

最新报告 `.data/evaluations/living-memory-live-r4yP9a/report.json`：8 个场景、16 项流程检查通过。覆盖第一批整理、跨批次关联、无重复子集、跨会话原文问答、仅确认活动、问题等待跨重启、简短地点回答续接同一 Run、纠正后的新会话回忆及无依据问题。第二次隔离运行 `living-memory-live-0l4OTX` 的 15 项断言虽通过，对照记录发现重复候选；该问题已修复并纳入最新断言。首次失败运行 `living-memory-live-lbBeHG` 保留，未覆盖原结果。

真实调用揭示并修复了这些问题：原文中文日期未进入结构字段导致归组拒绝；严格参数模式中的空筛选和非视频时间 0 阻断证据读取；纠正后上下文丢失已回答问题；只改地点字段而正文保留旧值；后续重试返回较小分组留下重复候选。缺少真实指令引文、未读取来源或虚构结果 ID 的调用仍被拒绝，模型调整后继续；失败记录没有改成成功。

本次 Agent 对照原文、完整调用和公开原图，结果记录在报告的 `semanticReview`，不是独立盲评或用户人工确认：文字中的物品问答和更正后的地点正确；照片仍把咖啡杯误认为碗，并把杯碟图案误解为背景或织物。该次运行还将同一照片的两条观察拆为不同候选，后续补齐来源关联后做了专项修复与复核，见下文。这些观察保持未确认、无日期与身份，不进入已确认个人事实。更正后的摘要仍可能沿用“原文/观察记录称”的措辞，须结合独立的用户更正回执理解，不能当成旧原件逐字内容。因此不报告视觉准确率、活动归组独立准确率、规模吞吐或个人模型记忆成绩。

补充复核发现整理输入缺少原件身份，模型无法判断多条照片观察来自同图。现提供有界来源引用、素材种类、文字范围、照片区域和视频帧时间；移除 Pi 适配器中重复的业务校验，由业务服务统一核验归组。照片不再携带无关的文件字节范围，避免被误读成视频时间。真实模型专项报告 `.data/evaluations/source-review-piD864/report.json` 中，同图两条观察归为一组、同一文字文件的两个不同日期分别归组，四项检查通过；该报告复用此前公开照片观察并加入两条新的虚构写生记录，仅验证此项修复。

图片输入专项报告 `.data/evaluations/source-review-fVsCHv/report.json` 记录本地预览与 Pi 最终请求中的图片哈希一致，尺寸 1280×960。保持同一提取提示，分别请求 `auto`、`high` 细节后仍错误识别杯子和杯碟，未将 `high` 改动写入产品，也未将流程通过当作视觉质量改善。这只能确认客户端发出的像素，不能证明兼容网关内部的处理或模型身份。
