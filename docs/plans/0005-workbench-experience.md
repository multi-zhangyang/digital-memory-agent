# 工作台体验与性能

目标：让通用 Agent 的对话、执行记录和文件工作区形成一致的工作流程。Pi 提供执行基础，不以复刻 Pi 全部界面功能为目标。

## 本阶段

- 收敛导航、输入区和执行记录层级；主操作清楚，高级详情按需展开。
- 输入状态与会话输出分离；草稿延迟持久化，切换和刷新仍可恢复。
- 流式事件合并渲染，保留顺序、断线恢复、停止与排队语义。
- 历史消息复用、会话缓存、按需加载预览和设置，减少轮询。
- 文件区按需打开；文件、改动和终端统一入口；必要的会话控制继续可用。
- 验证桌面、窄屏、键盘、完整任务链路及同环境性能对比。

## 已实现

- 侧栏保留项目、会话与资料入口；首页取消重复会话列表。默认单个对话画布，工作区由用户主动打开。
- 思考合并为一个入口；连续工具调用归入执行记录，参数、输出、错误仍可展开。工具失败自动展开对应记录组。
- 模型、权限保留快捷入口，思考与资料范围归入任务设置。即时纠偏、Pi 原生 follow-up 与独立任务排队有明确的发送方式。
- 继续当前任务时锁定其模型与权限；新增资料自动切换为新任务排队。修复原生表单 reset 在提交前重置权限的问题。
- 草稿由独立外部 store 管理，仅更新输入区；300 ms 延迟保存，离开页面时补存。发送等待期间的新输入不会被完成回调清空。
- 文本、思考与工具增量以 50 ms 批量提交，生命周期事件立即处理。SSE 正常时取消任务轮询，断线保留自动重连和恢复读取。
- 复用完成的消息节点；最近 20 轮先渲染，更早记录按需展开。内存缓存最多 12 个会话，返回时先展示缓存再核对服务端状态。
- 设置、资料预览、会话渲染和代码高亮按需加载。思考区域不再提前加载图表、数学和高亮插件。
- 文件树按目录索引构建；文件内容先显示缓存再更新，大文本使用纯文本预览。工作区开关不会重建对话；点击文件改动直接进入改动页。
- 上下文、压缩、历史分支等集中在“会话控制”弹窗，仅打开后读取会话状态。

## 依据

使用 Exa 检索官方资料，原始结果保存在本地忽略目录 `.data/design-research/0005/`。

- [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines)：输入响应、键盘操作、URL 状态、渐进呈现。
- [React useDeferredValue](https://react.dev/reference/react/useDeferredValue)：保持输入及时响应、降低昂贵内容更新优先级。
- [AI SDK useChat](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat)：流式更新节流。
- [AI Elements Reasoning](https://elements.ai-sdk.dev/components/reasoning)：多段思考合并，避免重复指示器。
- Next.js 安装包随附 Lazy Loading 文档：按需加载客户端组件及重型库。

## 验证记录

实施前本机 Chromium、生产构建、1440 × 1000：首页脚本解码体积 2,729,047 字节；一次启动长任务 446 ms；40 次输入到下一绘制帧的中位数 31 ms、P95 62.2 ms。此为本机合成观测，不是用户现场 INP。


最终生产构建复测：

| 观测项 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 首页脚本解码体积 | 2,729,047 B | 813,009 B |
| 60 轮历史场景输入到下一帧中位数 | 80.8 ms | 15.0 ms |
| 60 轮历史场景输入到下一帧 P95 | 95.9 ms | 21.7 ms |
| 初始渲染轮数 | 60 | 20，其余按需展开 |

本机这次采样的首页启动未观测到超过 50 ms 的长任务；首次打开长会话仍有一次 176 ms 的长任务。以上是合成测试结果，会受设备、浏览器和负载影响，不能视为所有操作耗时的保证。这里的字节数为加载脚本的解码体积，不是压缩后的网络传输量。

验证通过：

- `pnpm typecheck`、`pnpm build`。
- `pnpm test`：24 项后端测试。
- `E2E_PRODUCTION=1 pnpm test:e2e`：12 项浏览器测试。新增 100 个连续片段的顺序与完整性、模拟 SSE 提前关闭后由 EventSource 重连、Pi 原生 follow-up、长历史展开/缓存返回、提交等待期间继续输入的保留。
- 桌面工作区、390 px 移动布局、权限确认、真实项目文件读写/脚本执行/回退、资料与记忆原有流程均回归通过。

这些浏览器任务通过真实 Pi、后端和数据库运行，外部模型为本地测试供应商；长历史是独立的浏览器渲染替身。本轮未调用付费模型做生成效果评估。界面继续使用 shadcn/ui 与 AI Elements，没有新增自定义样式表。

可复现实验（先启动生产服务，避免同时运行编译或其他负载）：

```bash
node tests/bench/workbench.mjs local http://localhost:3000
```

输出位于 Git 忽略的 `test-results/performance/local/`，包含首页、60 轮合成历史、截图、脚本字节数、主线程长任务、40 次输入到下一绘制帧的采样及 API 请求记录。脚本不调用模型、不修改服务端数据。界面截图可能包含本地会话标题，不应直接公开。

这里的渲染窗口不限制 Pi 的真实会话上下文；服务端仍保存完整历史。本阶段未加入人物识别、嵌入模型或个人模型训练。
