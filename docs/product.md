# digital memory 产品定义

digital memory Agent = 可替换的 AI + 基于 Pi 自定义的 digital memory Harness。AI 通过模型接口提供理解和判断；Harness 组织目标、上下文、工具、运行环境、任务状态、证据和交付。长期资料与记忆由独立业务服务管理。个人记忆模型是另一个通过训练获得参数记忆、可独立运行的产物。

## 核心任务

| 编号 | 用户目标 | 系统交付 | 验收依据 |
| --- | --- | --- | --- |
| M1 | 交给系统一批允许处理的资料 | 原件、来源、处理范围、可恢复作业 | 原件可核验，模型只接收允许的资料；无 Agent 会话也能处理 |
| M2 | 自动组织个人资料 | 可检索的素材观察、人物候选和事件 | 保留未知与推断；原图索引不因提取失败或未确认而消失 |
| M3 | 找资料、回忆经历并完成任务 | 有依据的回答、完整列表或可编辑成果 | 区分观察与事实，时间和人物条件正确，覆盖不足如实说明 |
| M4 | 核对、更正或停止使用记忆 | 新版本及受影响关联、索引和样本的更新 | 旧事实不继续污染上下文，来源与修订历史可追踪 |
| M5 | 准备个人模型训练数据 | 有来源和版本关联的训练、评测及待审资料 | 未确认事实不导出为训练真值；评测题关联训练题版本并逐对核对所考事实；可定位失败题、逐题记录依据并保留不能消歧的题待核对；训练题修订或转为待核对使关联评测重新待审；纠正后按原范围重建，保留未变更样本的核对决定及新旧版本 |
| M6 | 让个人模型独立记住经历 | 权重、训练记录和独立闭卷评测 | 与基础模型及检索问答对照；训练成功不代替记忆质量 |
| H1 | 让 Agent 自主完成实际工作 | 文件、脚本、网络、扩展、会话与可恢复任务 | 执行边界真实有效，过程可审阅，失败和未完成状态可见 |

## 使用方式

采用 Agent first：用户把媒体和目标交给 Agent，由它选择读取、处理、检索、核对与维护能力，跟进后台结果，生成、修订并交付可训练文件，之后继续协助训练和评估。核心贡献是完成用户的数字记忆任务。直接操作页面是同一业务服务的另一入口，不能要求用户代替 Agent 分批处理、搬运结果或补做已有能力覆盖的操作。

“越用越懂你”通过可追溯的长期记忆、确认偏好及纠正记录实现，后续任务按需检索并采用最新依据。持续使用和会话变长不意味着模型参数已经学会个人经历；参数记忆需要另行训练与评估。

以任务为默认入口。用户可以直接提出目标、选择资料，必要时指定工作目录。通用文件、终端、改动和 Pi 会话能力继续可用。资料、记忆、数据集、处理记录及待核对事项提供直接入口，任务保存相应引用与成果。

资料库直接上传按启用的策略进入后台；会话附件先保留原件，发送目标后再由 Agent 决定如何处理。模型未配置时保持待配置；旧资料不因软件升级自动外发或重新提取。资料库维护独立于对话运行，任务是它的提交者和结果使用者。

## 信息的含义

- 原始资料：原件和来源，不自动证明用户拥有、到访、偏好或身份关系。
- 素材观察：处理器提取的内容，可查找、对照原文或像素，必须携带核对状态及不确定性。
- 个人事实：满足用户确认或已有本人陈述分级规则的记录，保留有效时间与修订。
- 检索索引：可以重建的派生数据，嵌入相似度不是事实正确率。
- 训练资料：冻结事实版本后生成、核验的样本，语义仍需核对。
- 参数记忆：真实训练所得模型能力，通过独立评估确认。

## 能力与交付标准

每项能力分别报告实现、配置、验证程度和当前可用性。后台作业完成表示处理结束；Agent 的交付应包含产物、依据、覆盖及未完成事项。用测试替身验证的协议或状态，不描述为真实识别质量。

复核需要实际读取对应原文或像素，留下本次读取和修订的依据。查到摘要不算核对原件，完成草稿修订不提高事实确认等级。可训练问答需要离开当前会话仍能解释人物、动作与时间；日期未知时保留未知，无法消歧的样本保留待核对或排除，并退出训练/评测文件。机械检查、Agent 判断与独立效果验收分别记录。

新增功能须关联上表的核心任务或执行可靠性。技术选型先写预期改善与验收办法，再依据同条件的基线和独立材料决定；已知失败保留，不能通过修正测试答案掩盖。
