# Agent first：图片与文字任务

状态：本阶段功能实现、回归及本机运行版本切换完成。会话内交办、确认、纠正、样本核对与文件交付已用真实模型贯通；视觉内容质量尚未通过独立核对，不将工作流通过等同于识图质量通过。

对应产品任务：M1–M5、H1，以及后续任务采用已确认偏好。M6 的真实个人模型训练仍未实施。

## 已确定的行为

- 支持静态图片和 UTF-8 文字。只发附件默认整理；明确目标由 Agent 决定使用哪些能力。
- 会话上传暂存原件和本地索引，外部提取由发送后的 Agent 任务提交；资料库直接上传仍按自动策略处理。
- 混合批次自动使用分别配置的处理模型，单份失败不阻断其余资料，真实结果与未完成项进入会话。
- 明确的确认、纠正和停用指令在既定权限内直接执行；模型观察保持待核对，不冒充用户确认。
- 修改通过共用业务命令服务完成，持久保存版本与回执。Agent 自己修改后刷新上下文继续交付；外部变更与取消仍执行失效边界。
- 会话内生成、检查和修订训练样本，核验真实训练、评测、待审和版本清单后交付下载。Agent 审阅不冒充用户确认，错误样本保留排除记录。
- 已确认的偏好与纠正进入后续任务的依据，检验持续使用中的个性化行为。
- 视频、音频、PDF、真实个人模型训练继续后置。

## 已交付行为

### 从媒体到整理结果

会话上传使用延后提取的入口，只发附件即可创建默认整理目标；系统生成的目标不当作用户原话写入记忆。上传失败逐份保留并可重试。资料库上传继续采用独立入库策略。

同一作业按素材选择文字或照片处理模型，保存每段实际模型与执行状态。模型缺配置、非法 UTF-8、被停用来源与单段失败不阻断其余素材。长文重试重新生成有界片段，重复素材保留每份原件的覆盖记录。处理、读取和生成结果均回到同一会话，刷新页面后仍可查看。

### 会话内维护记忆

HTTP 操作与 Agent 工具共用 `MemoryCommands`：事务内检查权限、范围、版本和指令依据，保存前后版本与幂等回执。明确的确认、纠正、停用、人物及事件关联可以直接执行。一般整理请求、默认目标、上传正文或助手文字不能冒充用户的确认指令。

`inspect_memories` 提供绑定本轮已读记录与版本的 `m1` 等短引用；样本检查提供 `s1`。引用跨重启保留，但不跨任务复用，也不自动升级到新版本。检索的可选条件允许 `null`，无需模型编造人物或事件 ID。

本轮自行修改后通过 Pi 上下文适配重建当前依据并继续任务，保留界面与会话历史；外部纠正或停用会在工具、输出和完成边界阻断过期运行。排队任务开始时采用最新版本。命令回执和真实指令消息纳入后续数据集依赖，删除相关消息也会使旧交付失效。

### 交付可训练文件

Agent 构建数据集后分页读取样本及冻结正文，批准、修订或排除样本；服务检查来源、版本、答案片段、重复问题等机械条件。审阅标记为 `agent-reviewed`，与用户事实确认分开。

修改后后台重新导出，不再次生成已提交样本。交付工具读取实际文件，核对来源有效性、SHA-256、条数及训练和评测答案对应关系，再提供 `training.jsonl`、`evaluation.jsonl`、`review.jsonl` 与 `manifest.json`。聊天链接和工具附件均可下载；过期、空训练文件或不对应的评测不能被描述为已交付。

确认偏好由独立记忆服务保存，后续任务按需取用。真实验收中的“日期从新到旧”影响了下一份资料的整理顺序；这证明本场景的持续偏好使用，不代表已训练模型参数。
