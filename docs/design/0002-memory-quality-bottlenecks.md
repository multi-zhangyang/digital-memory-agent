# 记忆质量瓶颈与技术取舍

关联 M3 查找回忆、M4 纠正、M5 训练资料和 H1 执行可靠性。调研日期：2026-10-05。公开资料通过 Exa 检索并读取原论文、作者仓库或官方文档。具体实现和对照结果见[阶段 31](../plans/0031-dataset-answerability.md)。

## 当前瓶颈

已有代码完成了资料入库、冻结来源、生成、审阅、修订、配对、恢复与文件交付。继续扩充界面或增加“完成”状态，不能证明交付的问答适合训练。当前主要缺口是：

1. **引用存在不等于问答正确。** 错误人物、错误日期也可能是原文中的连续字符串。题干可以暗含原文从未确认的购买、所有权或日常偏好。
2. **同一个答案不等于同一个所考事实。** 两个人买花和拍花可能都对应“白色”，但前一道训练题不能支撑后一道评测题。
3. **审阅文字不等于实际决定。** 真实对照中出现依据写着“应该 defer”，工具却提交 approve 的情况；若程序只保存自由文本，错误配对会进入评测文件。
4. **局部来源不足以保证全库消歧。** 不同记录里的同一同行人、地点、周末仍可能对应不同经历。现有后台按单条冻结记忆核验，不能据此声称完成跨来源事件消歧。
5. **当前缺少足够的质量测量。** 历史的协议通过、可下载文件和小样本复核，不能代替错误认可率、正确题保留率、纠正后的旧事实使用率或模型闭卷效果。

## 可采用的研究方法

| 研究 | 与项目相关的方法 | 采用边界 |
| --- | --- | --- |
| [Source2Synth](https://arxiv.org/abs/2409.08239)，2024，v2 更新于 2025 | 从真实来源生成，再按可回答性整理数据；生成和筛选分开评估 | 本项目采用来源与可回答性分层，未复现论文的切片训练、中间模型或下游训练成绩 |
| [Chain-of-Verification](https://aclanthology.org/2024.findings-acl.212/)，ACL Findings 2024 | 回答核验问题时隔离原候选答案，减少沿着原错误继续解释的影响 | 用冻结来源和问题单独作答，之后才对照候选答案；相同模型的两次请求不等于独立裁判 |
| [Provenance-Grounded Gating and Adaptive Recovery](https://arxiv.org/abs/2606.11127)，2026-06 预印本 | 保留精确生成来源；区分来源忠实性与题目质量；用有标签的错误注入比较诊断修复和盲目重试 | 论文的生成器和裁判集中在 Qwen 系列，收益随裁判、生成器规模变化，顺序核验仍有延迟；只借鉴对照方法，不移植其阈值或成绩 |
| [Memora](https://aclanthology.org/2026.findings-acl.1337/)，ACL Findings 2026 | 在记住、推理和推荐任务中考察持续更新；FAMA 对使用已失效记忆施加惩罚 | 后续增加“纠正后仍引用旧事实”的显式负指标，覆盖旧会话、工具历史、索引、训练样本和文件交付 |
| [LongMemEval-V2](https://arxiv.org/abs/2605.12493)，2026-05 | 区分静态状态、动态状态、操作流程、常见失败和错误前提；评估有界证据与查询延迟 | 该任务是环境经验记忆，适合 H1 的操作知识，不把环境操作经验混入个人事实，也不把其榜单直接当个人记忆评测 |
| [TMEM](https://arxiv.org/abs/2606.04536)，2026-06 预印本 | 从经历蒸馏监督并进行在线 LoRA 更新，研究数据提取策略如何影响后续行为 | 说明参数记忆值得独立实验；当前个人训练仍暂停，不能把检索索引或上下文总结称为已经学入参数 |

这些研究给出的共同方向是保留来源、隔离错误反馈、测量更新与失败。它们没有证明“增加一次模型审阅就能保证正确”。项目必须用自己的资料形态做对照，分别报告正确性、覆盖、成本和延迟。

## 推进次序

**第一步：提高每条训练问答的可核验性。** 后台先在不含候选答案、现有配对和审阅结论的请求中，根据冻结来源作答，区分可回答、歧义与不支持。程序给原文编号，模型选编号，证据直接从原文恢复，避免抄写时改标点或拼接日期。再对照候选问答、最终题干和训练评测所考事实；修订后的题干重新核验。遇到不能处理的题保留真实失败或待核对，不通过反复重试凑齐数量。

验收同时看：来源支持、人物和动作方向、时间可解释性、错误前提、训练评测配对、最短明确答案、错误认可和正确题保留。可用条数只是覆盖指标。保存原始请求、输出、拒绝及最终文件，记录调用数与延迟；开发材料、已用于诊断的回归材料和后续固定对照材料分别标明。

**第二步：评测跨来源事件与纠正传播。** 用多个相似事件及多轮事实变化，比较“正确原文已经给到模型”与“从完整索引检索”的结果。前者失败应改理解与核验，后者才定位召回、时间条件或读取范围。把旧事实误用、未确认观察误当事实、未知信息编造单独计数。需要扩大上下文时，通过范围受控的相关来源召回实现，不能默认外发整个资料库。

**第三步：把可靠执行经验用于 H1。** 复用实际失败、工具参数与恢复断点形成操作经验，评测服务重启、用户补充和新会话接手时的成功率、重复副作用和成本。操作经验与用户事实分开存储；程序仍负责后台恢复和权限。

**个人模型恢复训练后：** 先做冻结数据快照上的基础模型、训练后闭卷、检索辅助问答三组对照，再考虑在线 LoRA 或学习记忆策略。评测至少包含不同问法、未知拒答、相似事件、时间变化与新旧知识保留。研究方案、已安装工具和真实 GPU 运行分别记录。
