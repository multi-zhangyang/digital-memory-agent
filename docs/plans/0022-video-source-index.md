# 视频原件索引与人物出现

状态：功能、本地模型、真实 Agent、回归、恢复与本机启用已完成。承接[视频画面与时间证据](0021-video-memory.md)，对应 M1–M4、H1。个人模型训练继续暂停。

## 交付目标

1. 独立后台按配置对原始视频抽样，使用现有本地 SigLIP2、YuNet/SFace 建立画面索引和人物出现，不依赖主 Agent、生成描述或观察确认。
2. 每帧保存时间、原件和画面摘要、模型、真实进度与失败，重启恢复并复用完成帧，失败可重试。修改间隔与编码器后按新策略维护。
3. Agent 与直接页面可通过内容查找到具体画面、读取原件并定位播放。检索与人物关联按实际帧时间限定，未知身份不自动成为个人事实。
4. 人物核对显示原件与视频时间，确认、合并和拆分继续使用同一业务命令。原件停用与所选范围在候选限制前生效。

复用已有编码器和验证工具，不改模型选型，不将候选相似度、抽样覆盖或状态完成解释为身份、动作或个人参数记忆。只增补实际功能所需验证。

## 实现

原始视频入库后，独立索引服务按持久策略解码画面、调用已有本地 SigLIP2 和 YuNet/SFace，逐帧保存时间、视图摘要、特征和进度。帧结果不创建 MemoryEntry，不需要主 Agent 或人工确认。单帧失败保留已完成工作，重试复用已完成帧；重启恢复未完成状态，修改间隔维护新帧并停用旧抽样命中。

`search_evidence` 支持 `frame:` 原件命中与人物/候选筛选，`read_evidence` 读取固定时间画面；`inspect_source_people` 让 Agent 在没有描述时取得候选组、当前版本和出现来源。未知候选保持未知，整组确认仍遵循用户命令和范围。事实与人物关联同时匹配来源摘要及帧时间，不能把一个时点的身份扩展到同一视频的其他画面。

处理中心展示真实逐帧状态，运行期间自动刷新。素材检索和人物核对支持画面查找与定位播放，均组合现有官方组件。移动断点使用同一主页面实例，已打开的核对窗口、筛选和表单不会因改变尺寸而丢失。业务、原件读取和 UI 来源继续共用同一接口。

## 已发现的问题与限制

- 首次本地运行 `video-index-real-YBNnZk` 保留失败：第一段自然视频的音轨长于画面约 21 毫秒，按文件总时长抽出的末帧不可读。现在按 FFprobe 视频轨时长取尾帧，提取版本为 2；复测 16 帧完成。首次恢复验证的备份路径位于资料目录内，正确被拒绝；验证工具改为新建外部目录，没有绕开备份规则。
- 首次真实 Agent 运行 `video-index-real-6bbXpO` 检索失败仍保留：新人物筛选参数只接受 UUID，模型在无筛选时填全零占位 ID。工具现在明确支持 `null` 表示无筛选；`A6OH5d` 实际返回空筛选并成功检索，不把虚构 ID 当作有效对象。
- 首次浏览器实际索引用例在移动断点关闭所有人物核对窗口，暴露主页面重新挂载；保留主实例后相同用例通过，没有删去原尺寸切换检查。
- 自然视频索引及“人物走路”候选检索成功，但检测有明显遗漏：口罩片段只检测到其中一位人物的后 3 帧；另一段多人、侧脸片段只检测 9 处，多个较小区域没有可用特征，重复人物也有分组断开。已逐帧查看原件及检测框，报告保留每帧结果。不声明完整覆盖、自动知道姓名或自然相册级关联质量。
- 最多 120 个抽样画面，不能证明帧间事件或声音。旧抽样和旧特征保留审计数据但不作为当前命中；没有视频动作跟踪、按时间段停用或训练权重更新。
