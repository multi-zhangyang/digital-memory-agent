# 阶段十六：照片处理模型与界面精简

> 历史阶段记录：保留当时的决策、实测和限制。当前产品以 [产品定义](../product.md)、[架构](../architecture.md) 和 [Harness 重构计划](0018-harness-refactor.md) 为准。

状态：实现、回归及本机更新已完成。临时调用限制不作为产品默认配置；模型由用户配置和任务选择决定。训练保持暂停。

## 决策与边界

Agent 调用工具、分析结果、调整步骤并协助用户完成任务。长期资料、记忆账本、检索与批处理属于独立业务服务，参数记忆属于未来实际训练的个人模型。本轮没有将这些职责转入主 Agent。

照片服务增加可持久保存的默认处理模型。主 Agent 可以独立选模型，照片任务使用服务配置。保持已有队列、回执和事件反馈，不增加多模型自动复核或 Agent 逐图轮询。代码只补实际模型选择和计量行为，界面保留状态、结果、来源与操作，删去重复说明。

## 实际改动

- 「设置 → 个人记忆」可选择照片处理模型，照片导入默认使用该值；包含图片的 `process_assets` 工具采用同一配置。显式模型不可用时显示失败，不静默切换会话模型。设置随数据库保留，无新增迁移。
- 照片计量计入 Pi 单列的缓存写入。此前供应商输出常为 `input: 3`、`cacheWrite: 2647`；实际输入应为两者与缓存读取之和，不能据此认定图片没被传入。
- 照片、人物、事件、数据集及依据面板缩短重复说明，继续使用官方 shadcn/ui 和 AI Elements；图中文字、未知身份、待核对、失败、校验与整图停用范围仍保留。
- 新增独立照片评测命令与六图清单，实际请求只带中性文件名和预处理像素。来源、许可与核对项不进入模型上下文，输出不写入个人记忆库。

## Luna 的真实对照

六张公开照片包含杯碟与弯勺、倾倒饮品、两种面碗、雪地三人和树下两人。来源与原件摘要见 [固定清单](../../examples/quality/photo-processing.json)，执行方式见 [评测说明](../../examples/quality/README.md)。沿用先前固定的短提示对照原提取器，不根据这批新图继续调词。

| 同模型、相同六图 | 原提示 v2 | 隔离短提示 v3 |
| --- | --- | --- |
| 有效结构化响应 | 6/6 | 6/6 |
| 有明确内容错误的照片 | 2/6 | 2/6 |
| 输入计量合计，含缓存 | 16,440 token | 15,372 token |
| 输出计量合计 | 1,772 token | 1,397 token |
| 单图调用中位耗时 | 5.07 秒 | 4.50 秒 |

两版都把筷子及夹起的宽面条写成白色架状结构，树下照片都误写两人手相接；原件中左侧人物双手垂下，只有右侧人物抬手。短提示还漏掉面碗所在织纹桌面、橙色块和纸垫位置。雪地背景的狗已经放大原件核对，不算错误。其余四图虽没有确认的错误，仍有遗漏，不能报告为四图完全正确或通用准确率。

因此正式处理器保留 v2 的请求及去重版本，仅上线真实计量修正。缩短提示没有证据支持视觉质量改善，不作为新版本发布。原报告保存在 `.data/evaluations/photo-processor-stage16-baseline-kagiEB/` 和 `photo-processor-stage16-luna-2Dk4Dp/`，逐项核对见各自 `content-review.json`；v3 源码另存于忽略目录。

另一模型的独立六图实验有五次结构化响应失败，原始失败记录保留，不能隐藏失败后宣称方案可靠。

## Exa 技术调研

通过 Exa 查找原始论文及官方模型卡，调研记录保存在忽略目录。与本轮决策直接相关的是：

- [MIOH，CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/papers/Min_Fine-Grained_Multi_Image_Object_Hallucination_Benchmark_CVPR_2026_paper.pdf)将物体、数量、属性与空间关系分开核对。本项目六图核对沿用这种拆分，结构合法与描述正确分别报告。
- [OVFact](https://aclanthology.org/2025.findings-emnlp.1058/)关注长视觉描述中的事实精度与覆盖。短输出会省计量，也可能只因省略细节而少出错，本轮不将省略算质量改善。
- [Qwen3.8-27B 官方模型卡](https://huggingface.co/Qwen/Qwen3.8-27B)提供原生图像、视频输入的公开模型方向；本机未部署或验证该模型。

论文与模型卡不是当前兼容网关效果的证明。客户端图片摘要一致只证明提交了对应预览，无法证明网关内部模型身份或描述正确。
