## 实现

`read_evidence` 与 `read_asset_text` 返回本轮读取引用 `e1`、`e2` 等。`propose_memory.sourceRefs` 选择完成读取的原文页或实际送达模型的画面；应用从持久工具结果取出原件、时间、视图和局部，模型不能自行提交来源像素元数据。多画面视频须明确选择，单幅或旧文字调用保留兼容路径。引用绑定任务，重启保留，不从检索摘要生成读取依据。

Agent 与直接画面保存复用 `MemoryDrafts`，提交前检查当前原件字节，草稿不设 `acceptedBy`。视频窗口使用现有 AI Elements Attachment 与 shadcn Dialog/Field/Textarea，只有标题、内容和可选事件日期。保存后的核对入口接入既有记忆版本命令。局部证据预览按保存的原始像素区域重建，避免显示整幅原件却匹配局部摘要；播放与来源链接使用请求时间复现画面，实际时间用于显示。
