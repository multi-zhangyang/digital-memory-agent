## 最终实现

- 从方向修正后的原件截取局部后再缩放，返回实际像素区域、原件及局部摘要。前端复用官方 AI Elements Tool、Attachments、Sources 和现有 shadcn 表单，显示真实读取、失败与时间检查结果。
- `sourceReads` 只从本轮持久化的成功读取构造；整图、局部和字节分页证明实际来源读取，不能证明模型理解正确。观察修订仍为 Agent 草稿，不冒充用户确认。
- 新旧文字读取共用完整原件核验和 UTF-8 分页，拒绝改动、符号链接、停用及取消后的结果。原文与当前页关联的确认修订并列返回，用户纠正值不再被旧原文覆盖；关闭记忆取用不返回确认上下文。
- 历史成果不因无关偏好变更隐藏，保存写入时的记忆版本；依赖停用继续阻断。上下文刷新显式携带本任务实际变更，避免把修订后的正确值误说成从未修订。
- 时间检查由样本读取、修订和实际文件下载共用；不明确或不受冻结来源支持的日期须修订或排除。旧版 ready 样本也重新检查。
- 明确保存结果及整份所选资料确认请求结束前核对实际交付；发现遗漏在同一 Pi 会话补齐一次，仍不足则失败。部分确认与询问操作方法不触发整批确认检查；失败后台作业保留原失败原因。
- 后台无效偏好提取最多自动重试一次，次数持久化。匹配同一真实用户消息的 profile 草稿，经独立提取及分级通过后可按策略确认；用户明确纠正自己的消息画像草稿可进入用户确认。素材观察、推断、冲突、停用及其他消息旧草稿不沿此路径自动确认。
