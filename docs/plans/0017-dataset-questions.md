## 实现

`build_dataset` 和 WebUI 共用 `DatasetService`。用户可选择固定模板或已配置模型；工具使用 `generation: "model"`，可指定 `modelId`，否则使用本次任务所选连接。后台逐条处理冻结清单，通过 `MemoryProcessors` 调用专用生成能力，只发送当前记录和时间信息。Agent 提交任务、接收完成通知并处理结果，进度与恢复由服务保存。

模型返回训练问题、原文答案与评测问法。评测题通过训练题索引引用答案，由服务确定对应关系，不要求模型重复抄写答案。引用须在当前正文中，问法不能重复；模型输出全部进入待核对。核对后训练题写入 `training.jsonl`，评测题写入 `evaluation.jsonl`，待审题和版本清单另存。评测针对相同事实的不同问法，不代表未知事实测试。

已有样本在核对或中断恢复时不重新生成；取消和失败保留已提交部分。记忆、人物、事件或原件变更会使相关训练题与评测题失效，下载重新核验来源和文件摘要。备份恢复包含评测文件、样本核对状态和依赖。界面增加生成连接选择、调用计数与训练/评测标识，继续组合官方 shadcn/ui；运行中的作业沿用现有 AI Elements 和真实后台事件。

## 验证

- 后端全量 106 项通过；最终生成接口调整后，13 项数据集回归再次通过，覆盖来源范围、一次通知、核对、恢复、失效、配置切换和归档。
- 类型检查、后端编译、前端生产构建通过。11 项浏览器流程通过；最终接口调整后，3 项数据集与事件浏览器流程再次通过。浏览器使用本地模型协议替身，验证真实 Pi、HTTP、SQLite 和界面集成。
- 六条虚构开发记录实际调用配置供应商，最终生成 12 道训练题、6 道评测题，均保持待核对。输入计量为 2,852 token，输出 648 token。未创建 Agent 会话或模型权重，未写入实际用户资料库。

开发中先发现评测题询问训练未覆盖的关系事实，再发现要求模型重复答案字符串会造成一次校验失败，最终改为引用训练题。前两轮原始结果保留在 `.data/evaluations/dataset-questions-TBn4df/`、`dataset-questions-BpaJ30/`；最终报告和逐题核对在 `dataset-questions-4ckDK2/`。这些是同组开发回归，不是独立保留集准确率。

最终 18 题中仍标记两项语义问题：一题的答案只有代词，另一道评测题在题干中提示了答案。没有自动确认这些题。引用匹配只能证明片段来自原文，不能保证问题适合训练或评分；当前尚未验证训练效果。

Exa 调研参考 [Source2Synth](https://arxiv.org/pdf/2409.08239v2.pdf) 对来源约束与可回答性筛选的区分。本阶段落实来源引用、题目对应关系与核对入口，没有复现论文训练实验。
