# 第一阶段：项目框架与 Pi WebUI

> 历史阶段记录：保留当时的决策、实测和限制。当前产品以 [产品定义](../product.md)、[架构](../architecture.md) 和 [Harness 重构计划](0018-harness-refactor.md) 为准。

## 目标

建立本地 Git 仓库与可运行的工程框架，完成 WebUI、Pi 接入、会话持久化和原始素材管理。用户后续提供 Agent API；个人模型训练、Colab CLI、人物识别、Embedding 和向量索引不属于本阶段。Embedding 使用 API 还是本地部署保持未决。

## 接口范围

提供健康状态、公开模型配置、会话创建/列表/历史/发送/取消、素材上传/列表/内容读取。流式消息采用 AI SDK UI 协议。模型凭据仅在服务器解析，未配置时显示说明，不生成模拟回复。

## 验收

无 GPU 与 API 密钥也可启动界面。配置 API 后可调用真实 Pi 会话。测试替身只用于测试，验证流式协议、错误、取消和隔离；真实供应商调用需用户提供 API 后单独验证。会话和素材跨重启保存，浏览器可预览支持的图片和视频。人物识别、检索与训练页面不展示虚构数据。私人运行数据与密钥不进入 Git。

## 本阶段落地与后续边界

Agent 通过独立 PiRuntime 适配层集成 Pi SDK，公开契约不包含供应商凭据。模型协议支持 OpenAI 兼容 Chat Completions 与 Anthropic Messages。通用系统工具暂未开放。

素材以原件和元数据保存，尚未解析、建立人物关系或送入模型。长期记忆检索、嵌入后端选型、训练样本流水线和 Colab CLI 集成均留待后续方案，不把页面入口计作这些能力已经实现。

本地 Git 已初始化 main；未配置远程仓库。当前机器未设置 Git 提交身份，尚未创建首次提交。
