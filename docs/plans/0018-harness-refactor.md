- 未确认观察作为待核实证据检索；事实召回与训练导出继续执行确认规则。
- 重构现有文字、照片、记忆、检索、数据集、工作台和 Pi 接入。视频处理与真实训练继续后置。
- 保留当前 Pi 1.0.0、编码器及排序基线。通过 SDK 正式接口自定义 Harness，不依赖上游未完成接口。
- 保留原件、会话、配置、稳定 ID、来源、核对状态和修订历史。

## 实现结果

- Harness、Pi 集成、应用装配、记忆服务与通用存储分目录。`PiHost` / `RuntimeContextPolicy` / `MemoryData` / `MemoryProcessors` / `TaskJobDriver` 明确边界；旧模块导出、HTTP 和稳定 ID 保持兼容。共享契约按领域拆分，保留原包入口。
- 产品定义落到四类任务、原生 Pi Skills 与提示模板、任务上下文、能力注册、模型用途配置、资料范围和交付。支持用户同名资源覆盖，复用 Pi 公开 SDK，不引入第二套 Agent 循环。
- 持久事件与消费者回执连接自动入库、六类业务作业和任务续接。归属区分任务与资料库，停止对话不会误停共享维护；重复事件、重启与索引重建不复用旧作业修订号。
- 原始文字和图像独立建立索引，新增 `search_evidence` / `read_evidence`；保留来源摘要、版本、权威性、陈述/观察/推断类型和不确定性。正文按 UTF-8 分页，旧引句和标题不污染修订后的读取。
- 任务入口、跨目录任务列表、素材内容检索、处理与核对、数据集页面及模型设置使用已有官方组件。文件、沙箱、审批、MCP、会话分支、压缩与流式历史继续可用。
- README、架构、本地处理方案与文档索引指向当前产品；0001–0017 和设计研究添加历史标记，保留既有失败及真实实验。AGENTS.md 只写长期原则。

## 复现与后续边界

```bash
pnpm typecheck
pnpm test
MEMORY_NEXT_DIST_DIR=.next-validation pnpm build
MEMORY_NEXT_DIST_DIR=.next-validation E2E_PRODUCTION=1 pnpm test:e2e
pnpm --filter @memory/agent eval:harness:migration /已停止服务或一致备份的数据目录
# 已配置真实模型和本地编码器，使用固定的公开图片与虚构文字
pnpm --filter @memory/agent eval:harness:product
```

当前后台在一个 Node 服务和独立本地特征进程内运行，事件是至少一次投递；模型调用可能在中断后重试，不声称外部副作用恰好一次。处理中心显示近期作业，不充当完整历史统计。旧根目录转发与方法兼容层保留给现有调用者。混合文字/照片的显式处理批次仍共用一个支持图片的模型；自动入库按类型分别选择模型。编码器维度和指纹是当前适配契约，本次没有更换模型或增加任意编码器配置界面。

视频、真实个人模型训练和公网服务继续后置。下一步应针对独立材料评估视觉与问法质量，再决定处理器或模型方案；不能继续堆通用平台功能代替这些核心任务验收。
