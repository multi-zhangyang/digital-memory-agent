# 阶段十一：自动记忆与可靠召回

> 历史阶段记录：保留当时的决策、实测和限制。当前产品以 [产品定义](../product.md)、[架构](../architecture.md) 和 [Harness 重构计划](0018-harness-refactor.md) 为准。

## 目标与约定

在现有 Pi 工作台和文字记忆闭环上，完成自动记录、人物与时间检索、纠正和停止取用。训练、文本嵌入、图片及视频理解仍在后续阶段。按来源分级：本人明确陈述可自动记录，推断、身份关联和冲突先核对。停止取用保留原始记录和撤销入口，同时阻止关联来源重新自动提取。

## 实施

1. 建立当前测试与检索基线，扩展可追溯证据、人物身份、有效时间和记忆版本。
2. SQLite FTS5 中文词项及双字索引，人物/时间过滤、有界查询和引用轨迹。
3. 独立、可恢复的后台消息提取队列，前台优先，幂等保存，独立自动记录设置。
4. 纠正、停用、恢复贯通索引、来源和 Pi 上下文；原会话继续可查看。
5. 现有 AI Elements / shadcn 工作台展示实际处理状态、证据和操作。

## 验收

固定虚构经历集覆盖信息提取、跨会话关联、时间变化、知识更新、未知问题及引用/代码/角色扮演负例；自动记录精确率目标 95%，Recall@10 目标 90%。证据校验、示例隔离和关联来源防止重新提取必须全部通过。覆盖取消、失败、恢复、并发修改、同会话/压缩/新会话及重启后的遗忘。用一万条虚构记忆记录本地检索 P50/P95，普通检索 P95 目标 100ms。测试替身和真实模型结果分别记录。

## 后续路线

扩大文字记忆评测 → 照片原图与区域证据、人物聚类和身份核对 → 视频分段、转写及时间定位 → 依据检索评测决定嵌入部署。用户暂不训练，当前只准备 Colab CLI；经核验数据快照、小参数模型训练与关闭检索的独立评估留待后续，见[阶段十二](0012-colab-cli-preparation.md)。

参考：[LongMemEval](https://arxiv.org/abs/2410.10813)、[SQLite FTS5](https://www.sqlite.org/fts5.html)、[VisualMem](https://arxiv.org/abs/2605.28806)、[Immich 人物识别](https://docs.immich.app/features/facial-recognition)。

## 实施结果

- 增加消息证据、有效时间、人物身份与别名、记忆修订号和召回轨迹。旧数据库迁移前保存备份，索引可重建。
- 实现独立后台记录队列及前台优先调度，支持取消、重启恢复、手动重试和补记。消息与提取版本幂等，非法证据整体回滚；内部队列不受界面只显示最近记录的限制。
- 中文 FTS5 词项与双字索引参与排序，支持人物、已确认别名、有效时间及历史查询；日、月、年精度保留，过去事件不会因月份已结束而漏检。
- 纠正与停止取用推进 Pi 上下文版本，保留界面历史及原始依据，阻止关联来源自动重新提取。结构化字段修改也会使上下文失效，事务回滚不会误停运行。
- 前端组合已有官方 AI Elements Task / Sources 展示状态和证据，设置和人物关联组合 shadcn/ui Field / FieldSet、Switch、Dialog、Checkbox。活跃任务有界轮询，使用取消信号清理请求；输入草稿独立保留。组件来源和已有兼容适配见 [阶段十](0010-ai-elements-runtime.md) 与 [第三方说明](../../THIRD_PARTY_NOTICES.md)。

## 2026-10-04 续接记录

从 `main` 的未提交改动、该计划和本地评测报告恢复上下文。中断前已具备主体实现，但真实模型问答最初只有 4/8 通过，最终验证尚未完成。本轮继续修复：

- 将当前修订正文与旧标题、原始引句分开传给模型，避免原文中的旧日期覆盖用户纠正；原文仍可在界面核验。
- 明确历史查询和人物 ID 的语义，阻止模型把记忆 ID 当作人物 ID。
- 依据完整消息及同句上下文判断引文、假设和省略主语，不因提取器移除引号就自动接受转述，也不跨句借用“我”。
- 同文但不同消息分别保留依据；补齐超过 1,000 条历史任务后的恢复/取消，以及月精度事件的前后端日期筛选。
- 通用 Harness 测试显式关闭后台记录，当前记忆断言检查正文；评测脚本计入类型检查。
- 评测保存分步报告。第二版评分分别检查原子事实、对应记忆引用及生活变化/日期纠正是否实际完成；不再仅凭答案出现某个城市名计为通过。

## 验证记录

- 改动前：后端 41 项测试通过。
- 本轮 `pnpm typecheck`、后端 **58 项测试**、`pnpm build` 通过。生产构建在独立源码副本完成，原工作区未覆盖正在服务的构建。
- 本地检索：10,000 条虚构记忆，10 个问题各重复 5 次，Recall@10 **100%**，P50 **1.15ms**，P95 **2.68ms**。同一数据下旧关键词基线 Recall@10 为 70%，P50 29.58ms、P95 58.55ms。原始报告保存在忽略目录 `.data/evaluations/continuous-local-XYtLbA/report.json`。
- 真实模型：已配置的 `gpt-6-luna`，low 思考强度；12 条虚构消息。最终一轮自动记录精确率和预期自动事实覆盖率均为 **100%（7/7 次事实判断，包含一次重复陈述）**；五条负例没有自动确认，所有保存的依据通过原文校验。搬家冲突、身份关联和不确定经历保留待核对。确认生活变化和纠正日期后，**8/8 问答通过**，另一次停止取用后的同会话提问未召回已停用偏好，并明确表示不知道。已逐项检查实际回答。原始报告为 `.data/evaluations/continuous-live-TVXuEb/report.json`。
- 较早轮次出现过姓名/职业漏记、旧日期干扰和非法引句，报告继续保留；非法引句被拒绝且没有保存候选。本轮结果是修复后的固定小样本验证，不代表通用自然语言准确率或正式 LongMemEval 成绩。
- 浏览器：完整生产模式回归 **27 项通过**，包含本次新增的自动记录/原文/停用恢复、人物别名与设置、月精度日期筛选；手机截图已检查，输入草稿及页面宽度正常。默认测试端口冲突后，隔离副本改用 46427 / 46143 / 45957，测试仍使用独立数据和本地模型替身。

后端和浏览器回归使用本地模型替身，但实际经过 Pi、SQLite、HTTP、SSE、文件与权限边界。压缩后的停用测试构造了 Pi 压缩节点，再检查真实发送请求；真实模型评测没有代替完整压缩、长历史及大规模语义评估。所有评测素材均为虚构，未上传个人资料库。
