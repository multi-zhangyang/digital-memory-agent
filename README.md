# digital memory

一个以个人经历为中心的本地 Agent 工程。长期目标是建设两个独立产物：负责理解素材、管理记忆与调度任务的 Agent，以及通过训练承载个人记忆的模型。

基于 Pi 的通用 Agent 工作台已接入第一版文字记忆核心：批量导入经历、模型提取、原文核验、候选审核、画像与人物索引，以及跨会话召回。图片与视频理解、视觉人物识别、嵌入模型和个人模型训练继续后置。

## 启动

需要 Node.js 24 与 pnpm 12.6.0。脚本执行使用 Linux / WSL2 和 bubblewrap（Ubuntu 可安装 `bubblewrap`），当前环境已验证；无沙箱时会明确拒绝执行。无需 GPU、Docker 或外部数据库。在仓库根目录执行：

```bash
pnpm install
pnpm dev
```

打开 http://localhost:3000。Agent 服务默认运行在 http://127.0.0.1:4310。未配置模型也能使用界面和资料库；发送消息会保持禁用，设置页会提示缺少的配置。

在 WebUI 的「设置」中填写接口地址、API key 和模型名称，选择协议并设置上下文窗口、最大输出与思考强度，点击「保存并测试」。保存即时生效，无需重启。支持以下协议：

| 接口            | 协议                         | 默认地址                  |
| --------------- | ---------------------------- | ------------------------- |
| OpenAI 兼容接口 | Chat Completions / Responses | https://api.openai.com/v1 |
| Anthropic       | Messages                     | https://api.anthropic.com |

填写供应商提供的实际模型标识。兼容接口地址通常填写服务基址，不包含 `/chat/completions` 或 `/messages`。可以新增多个模型连接，并在同一会话中切换。这里接入的是 API 服务；ChatGPT / Claude 网页订阅本身不等于 API 凭据。

「已配置」表示配置完整；「保存并测试」会实际调用所选模型。支持的思考强度以具体模型和协议为准。配置初始值为 32,768 token 上下文、4,096 token 最大输出，可从前端修改。当前对话接入文本与工具结果，尚未启用图片或视频理解。

模型连接保存在私人数据目录的 `settings.json`，文件权限为 `0600`。页面只显示密钥是否已保存；留空保存会保留旧密钥。浏览器不持久化密钥。正在生成回复时，服务端拒绝修改模型配置。

可选地复制 `.env.example` 为 `.env` 调整服务端配置。`AGENT_PORT` 修改后须同步修改 `AGENT_ORIGIN`。默认 WebUI 端口为 3000；自定义端口可用 `PORT=3002 pnpm dev`，并在 `MEMORY_ALLOWED_ORIGINS` 中填写对应浏览器地址。显式环境变量优先于 `.env`；模型连接以 WebUI 保存的配置为准，环境变量只提供初始值。

## 通用 Agent

点击侧栏「打开文件夹」、新任务页的项目名称，或按 `Ctrl/Cmd+O`，选择已有的工作目录。可逐层浏览、筛选和显示隐藏文件夹，也可粘贴完整路径直接打开。在 WSL 中支持 `C:\Users\…` 这样的 Windows 路径（转换到 `/mnt/c/…`，需已挂载）。目录来自运行 Agent 的设备；若从另一台设备访问网页，选择的仍是 Agent 主机目录。

Agent 直接读写所选目录中的原文件，文件面板显示真实路径并支持复制。重复打开相同目录会回到原项目，刷新和重启后保留项目关联；目录被移动或断开时显示不可用，不会重新创建空文件夹。旧任务继续使用各自的原目录。也可用项目旁的「＋」创建空白项目，再导入 CSV 或代码。

通过聊天要求 Agent 读取、编写脚本、运行和检查输出。右侧「文件 / 改动 / 终端」展示实际文件、差异与过程输出；「会话控制」管理 Pi 上下文、压缩、历史节点和工具状态。项目的文件工具、Pi 会话、终端和回退使用同一个工作目录；应用私人数据在文件工具、检查点和沙箱中排除。

侧栏按项目显示任务，项目和任务分别保留输入草稿。输入 `@` 可以搜索当前项目文件和资料库，方向键选择、Enter 引用；`/` 列出当前可用的工作台命令、Skills 和模板。所选项目文件会以有长度上限的真实内容片段进入本次模型上下文，不自动读取整个项目。空输入框按 ↑ 可复用上次请求。

「改动」面板按运行轮次、文件查看差异，可以展开工作区、标记已查看、导出补丁和逐文件回退。在文件上添加审阅意见会将意见和该次历史版本加入输入草稿，发送后交给 Agent 继续处理。已有草稿会保留；已查看状态只表示用户的审阅标记。

| 操作             | 快捷键                                |
| ---------------- | ------------------------------------- |
| 命令与搜索       | Ctrl/Cmd + K，或 Ctrl/Cmd + Shift + P |
| 快速打开项目文件 | Ctrl/Cmd + P                          |
| 打开文件夹       | Ctrl/Cmd + O                          |
| 新任务           | Ctrl/Cmd + Shift + O                  |
| 审阅文件改动     | Ctrl/Cmd + Shift + G                  |
| 终端输出         | Ctrl/Cmd + J                          |
| 切换侧栏         | Ctrl/Cmd + B                          |

- Pi 原生 read、write、edit、bash，加上项目文本搜索、Exa 与公开网页读取。
- 每次运行可选只读、询问、自动；设置中可管理项目指令、工具开关和主机网络访问。默认终端不联网；开启主机网络后可以访问网络及本机服务，不再隔离网络。
- 输入框支持立即纠偏、Pi 原生 follow-up 和独立任务排队；支持停止、刷新恢复、重试与等待回答。
- 检查点支持逐行与并排审阅、补丁下载和逐文件恢复，点击历史回复中的改动会定位到对应轮次。存在后续修改时拒绝覆盖；从回复或历史节点创建新的会话分支，项目文件保持当前状态。
- 文件预览支持语法高亮，编辑支持 `Ctrl/Cmd+S` 保存。未保存的编辑在当前标签页切换任务、项目或关闭面板时保留；不写入浏览器存储，刷新页面前会提示。
- Skills、提示词模板、根目录 AGENTS.md、MCP HTTP / stdio 配置；已注册工具和状态可在上下文面板查看。本地 MCP 只读挂载项目，HTTP 支持静态请求头认证，OAuth 和任意终端扩展界面尚未适配。
- 手动/自动压缩、重试设置、真实思考内容、工具中间结果、模型连接新增和会话导出。

项目文件上传和工具读写每个最多 10 MB，Web 编辑正文最多 512 K 字符（请求体上限 1 MB）；检查点最多 5,000 个条目、64 MB，依赖和缓存不纳入比较。资料库原件仍使用下面的独立上传限额。项目配置更改会重建运行时，须等待活跃任务结束。

## 文字记忆

打开「个人记忆 → 导入经历」，可以直接写记录、批量选择 `.txt` / `.md` 文件，或选取资料库中的文字。选择已配置模型与思考强度后开始提取。每批最多 20 份、每份不超过 256 KB，最多分为 32 段；只有选中的文字片段会发送给模型。

「处理记录」显示真实分段进度、调用次数、输入输出计量与错误。可取消、重试未完成部分；服务重启后继续未完成的文字处理。相同内容与提取版本复用已处理结果，不重复提取，也不会把已排除或已纠正的记忆恢复成旧草稿。

「关于我」查看当前已确认画像，「时间线」按日期浏览经历，「人物」按原文提到的称呼查看关联记录。人物称呼索引不等于身份识别，同名不证明同一真实人物。所有模型提取结果先进入「待核对」，未经确认不参加个人召回。

每条候选保留原文引句、来源文件、字节范围、SHA-256、模型和提取版本。可以确认、纠正、排除或合并；现居城市、姓名、职业和工作单位等单值画像出现不同值时，需要明确核对并替代旧记录。旧版本和被替代记录继续保留，默认召回使用当前版本。

「虚构示例」包含四份由开发方编写的经历，实际调用所选模型生成候选。示例资料与记忆存放在独立的 `demo` 空间，即使确认也不会进入你的个人画像、默认资料搜索或 Agent 召回。原文见 [示例说明](examples/experiences/README.md)。

Agent 每轮自动取用有大小预算的已确认画像和相关记忆，也能用 `search_memories` 按关键词、人物和日期查询。旧的自动注入快照不再反复发送；历史记忆检索结果标记为过期。对话中的其他既有内容仍属于会话历史，关闭记忆开关不等于删除历史对话。

## 工作台能力

- 官方 shadcn/ui 与 AI Elements 组成单侧栏、对话和审阅工作区。项目和任务集中在左侧，文件、改动和终端输出按需打开。默认黑白深色，支持浅色主题、移动端抽屉和全局搜索。
- Agent 的消息、思考、工具参数与结果、审批、补充回答、队列、计划、附件、来源、终端和上下文统一组合官方 AI Elements；业务状态来自 Pi 与本地 Harness，组件与交互约定见 [AI Elements 接入记录](docs/plans/0010-ai-elements-runtime.md)。
- 新任务页专注输入，「所有任务」独立管理按项目组织的真实任务列表，可搜索旧任务、筛选进行中和已归档任务、恢复归档与收藏。
- 对话内上传、拖放、粘贴文件、`@` 选取资料、多附件预览与移除；输入草稿跨导航和刷新保留。
- 任务重命名、收藏、归档、删除、持久化排队、撤回、停止、重试与等待用户回答。
- 任务独立于浏览器连接运行，刷新或离开后可继续查看同一运行；执行记录集中展示思考、步骤和工具调用，展开可查看参数、输出与失败详情。需要授权时直接显示操作与审批按钮。完成后的文件清单可以直接打开对应轮次与文件的差异。
- Markdown 整理结果的预览、编辑、版本记录与导出；来源可打开到实际读取的原文范围。
- 记忆草稿、确认、纠正、排除、合并、冲突核对与修订记录；新任务从当前画像和本地检索中取用已确认内容。
- 资料集合、列表/网格、类型筛选、图片预览、视频播放、原件下载和字节范围读取。
- 可搜索的模型选择器、前端模型连接、协议、上下文窗口、最大输出、默认和本次思考强度配置；模型与 Agent 设置分别管理。

可从输入框上传一份文字记录，要求 Agent 整理经历，查看工具过程，打开整理结果和待核对记忆。确认记忆后，新任务可以查询；纠正内容会保留历史版本。

当前不做自动图片/视频理解、OCR、转写、视觉人物识别、向量嵌入或个人模型训练。文件检索按名称和类型匹配，记忆召回使用关键词与结构化条件。Pi 的上下文压缩不承担长期事实存储。

八项业务工具包括资料查找/读取、步骤更新、结果读取/写入、记忆检索/提议与等待用户补充。服务端限制选定资料范围，并校验来源是否实际读取。上传不会自动发送给模型；模型使用当前对话历史、按需读取的文字与召回的记忆。关闭新的记忆检索不会移除已在同一任务中交流过的内容。

## 数据与目录

```text
apps/web/             Next.js + shadcn/ui + AI Elements
apps/agent/           Fastify + Pi SDK 适配层
packages/contracts/   前后端共享公开类型
docs/architecture.md  总体架构
docs/plans/           阶段计划、进度与验证记录
examples/experiences/ 可显式导入独立空间的虚构经历
.data/                私人运行数据，不进入 Git
  settings.json       模型连接与服务端凭据
  harness.json        Exa、Skills、模板、MCP 与运行设置
  memory.sqlite       任务、素材、结果、记忆、版本与导入进度
  sessions/           Pi 原始会话文件
  assets/             以服务端 ID 命名的原始文件
  workspace/          默认项目文件
  projects/           应用创建的空白项目工作目录；打开的外部目录保留在原位置
  checkpoints/        任务前文件快照
```

默认单文件上传限制为 1 GiB，可通过 `MEMORY_UPLOAD_LIMIT` 修改。WebUI 的 API 路由流式转发请求和响应，Agent 将上传流直接写入文件；不会因 Next 默认重写代理的 10 MB 缓冲限制截断原件。预览取决于浏览器对格式与编码的支持，其他文件可下载查看。

`MEMORY_DATA_DIR` 可以指定其他目录，相对路径以仓库根目录为准。选择仓库内的其他数据目录时，须将该目录加入 `.gitignore`。备份时先停止服务，再完整复制数据目录，以保持数据库和文件一致。外部工作目录需要单独备份，数据目录保存其路径和运行检查点。

这是单用户本机应用，默认仅监听回环地址，目前没有登录系统和静态数据加密。密钥、素材、会话、数据库和模型权重均由 Git 忽略规则排除；请勿直接作为公网服务部署。模型调用会发送当前会话上下文到所选供应商，资料库不会整体上传。

## 开发与验证

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
# 已构建时，使用生产模式验证浏览器交互
E2E_PRODUCTION=1 pnpm test:e2e
```

`pnpm check` 顺序执行类型检查、服务端测试和构建。浏览器测试单独运行，使用 3001 / 4311 / 4312 端口和隔离的数据目录；不要同时构建与运行开发服务器，因为它们共享 Next 输出目录。系统缺少浏览器依赖时，可使用 `pnpm exec playwright install --with-deps chromium`。

服务端集成测试使用真实 Pi SDK，连接本地测试供应商，检查 OpenAI / Anthropic 协议、工具执行、流式输出、错误脱敏、取消、隔离、配置与持久化。浏览器测试使用官方 `@shadcn/helpers` 的 AI SDK 测试传输，覆盖执行中、完成、失败、历史恢复、配置保存和素材操作，不调用付费模型。实际聊天始终由 Pi 调用配置的真实供应商。独立的真实 API 验证记录见阶段文档。

生产模式本机运行：

```bash
pnpm build
pnpm start
```

源码仓库为 [multi-zhangyang/digital-memory-agent](https://github.com/multi-zhangyang/digital-memory-agent)，主分支为 `main`。长期原则见 [AGENTS.md](AGENTS.md)，当前核心进度见 [文字记忆](docs/plans/0009-memory-core.md)，Agent 组件接入见 [AI Elements](docs/plans/0010-ai-elements-runtime.md)。工作台操作见 [项目与审阅工作流](docs/plans/0008-workbench-workflows.md)，执行能力见 [通用 Agent](docs/plans/0004-general-agent.md)。第三方组件许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

设计依据见 [Agent 工作台研究](docs/design/0001-agent-workspace-research.md)，实现边界见 [架构文档](docs/architecture.md)。浏览器断线不取消任务。服务进程重启后，通用工具任务标记为中断，需要手动重新运行；经历导入根据已保存的分段进度恢复，不自动重放文件写入或脚本执行。
