# 日常记忆流程与 Pi 操作入口

本阶段推进 M1–M4 和 H1：资料交给 Agent 整理，补进已有活动，新会话找回，一句话纠正。本阶段不扩展训练及数据集审阅流程；个人模型训练仍暂停。后续交互与运行版本见[0039](0039-agent-interaction-and-tool-loading.md)。

## 已实现

- 整理作业自动保存当前用户原话、已送达补充和已回答问题，带参考时间与用户时区。用户说明可解释本批资料的日期、地点和同次经历；原始照片观察保持独立。
- `organize_memories` 和 `POST /api/memory-organization` 支持 `targetActivityId`。新增资料直接加入原活动，保留 ID、正文和确认状态，已明确拆开的资料仍分开。HTTP 可通过 `description` 提供说明。
- 回忆上下文把确认记忆关联到当前活动，Agent 可以继续读取新增资料，不只使用旧摘要。活动派生记忆的更正通过现有事件同步活动；只改地点时也更新未单独编辑的标题和正文。
- 活动详情新增“补充资料”，带活动引用和原来源回到输入框，沿用上传入口，不扩大所选资料范围。
- AI 和文字、图像、人脸特征仍由用户配置。特征服务未配置时，基础整理与关键词检索仍可使用。

## Pi 在界面中的入口

| 能力 | 入口与行为 |
| --- | --- |
| 手动 compact | 会话工具栏“压缩”；上下文页可填写保留重点；也支持 `/compact 保留重点` |
| 上下文用量与摘要 | 读取 Pi session，完成压缩后刷新；原生摘要节点随会话保存，刷新后可查看 |
| 会话树与分支 | 工具栏“会话”，选择节点后继续或新建分支 |
| 工具、Skills、提示模板、MCP | 工具栏“工具与扩展”及会话的“能力”页；已加载 Skill/模板可带入输入框 |
| steering / follow-up / 队列 | 沿用输入框的执行中发送方式和队列操作 |
| 自动压缩、重试、模型与思考级别 | 沿用 Harness 设置及输入框配置 |

本次复用官方 AI Elements Context、Artifact、Sources 和 shadcn 组件。Pi 继续提供执行内核；没有另建压缩或会话树实现。工具、扩展显示实际加载和激活状态。
